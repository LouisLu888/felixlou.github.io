# 编辑按

想给某一期加编辑按，就在这里新建 `<日期>.md`，例如 `2026-10-12.md`，写一两句你的看法（支持 **加粗** 和 [链接](https://...)）。

提交到 master 后，「AI 实干派 notes」workflow 会在一两分钟内把它合并进当期的网页、静态页和 RSS。删掉文件，编辑按也会随之去掉。

时间上的注意：给你自己的邮件在当期生成后立刻发出，不含编辑按；订阅者的邮件在太平洋时间上午 9:23 发出，这之前写好的编辑按会一起发给订阅者。

在手机上写：打开 GitHub App 或 github.com，进入 `ai-practice/notes/`，点 Add file → Create new file。
