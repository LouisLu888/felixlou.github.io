AI 自动评测别用默认 0.5 阈值，调一下差很多

Hamel Husain 用 100 条租房客服 agent 日志测了 6 个决策模型。调好阈值后，Perplexity 每 100 次评测成本 0.82 美分、F1 0.79；OpenAI Decisions 是 3.72 美分、F1 0.87。

谁·场景
AI 评测顾问 Hamel Husain 给一个公寓租赁 agent 做自动评测，目标是找出预订失败、漏转人工这类错误。
怎么用
决策模型给每条日志打一个 0 到 1 的失败概率。他拿人工标注做对照，用五折交叉验证调阈值，要求精确率和召回率都不低于 80%，再用 Platt scaling 校准概率。两步都写成了能直接交给 coding agent 的提示词。
结果
3 个模型满足 80/80 的要求。Liquid d1 和 Clef Flash 调阈值后提升最大，但仍未达标。Clef Flash 有一组日志平均预测失败率约 8%，实际有 60% 出错。
你可以试
手里已有几十条人工标注 pass/fail 日志的团队，保存好模型分数，把他的调阈值提示词交给 coding agent，不需要重新调用模型。
注意
样本只有 100 条，任务故意定得很宽。F1 默认精确率和召回率同样重要，实际业务很少如此。

Hamel Husain 在博客里测试了几款新出的决策模型，看它们能不能替代 LLM judge 做便宜的自动评测。常见的问题是直接用默认阈值 0.50：如果一个模型给所有出错日志打 0.40、正常日志打 0.10，阈值设在 0.30 就能完美区分，用 0.50 却一个都抓不到。

他的流程是：先定最低线，再调阈值，最后看成本。用作自动告警时，他要求精确率和召回率都至少 80%，在满足这个条件的阈值里选 F1 最高的。达标的三个模型中，Perplexity 最便宜，OpenAI Decisions 效果最好，成本约为前者的 4.5 倍。想把分数当置信度用，还要先校准；校准对 OpenAI 反而略有反效果。

他建议实际使用时每种失败模式单独建一个判断器，预计那时模型之间的差距会缩小。他的习惯是先用效果够好的大模型，再试小模型能否以更低成本追平。
