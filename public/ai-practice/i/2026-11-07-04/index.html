创作工具开始内置 MCP，agent 和人可以接力干活

前 Claude Code 团队成员 Thariq 注意到，Instagram Edits、Roblox Studio 已经内置 MCP：agent 先做一部分，熟练用户在熟悉的工具里接着改。

谁说的
Thariq，曾在 Anthropic 做 Claude Code，2026-11-06 在 X 上发帖。
核心观点
他喜欢这种模式：创作类 App 自带 MCP，让 agent 承担部分工作，熟练用户再在原有工具里协作、接手。
依据
他举了 Instagram Edits 和 Roblox Studio 两个例子。同一周，Tim Simmons 拍 AI 短片时也通过 MCP 从 Claude Code 调用 OpenArt 生成镜头。
对你的意义
查一下自己每天用的设计、剪辑或表格工具有没有 MCP 接口，先让 agent 做准备性的粗活，精修留在原工具里自己做。
争议·条件
Tim Simmons 的经验是，有些操作直接用平台界面更省事。MCP 只适合能说清楚、可以批量做的步骤。

Thariq 在帖子里说，他看好一种做法：Instagram Edits、Roblox Studio 这类创作工具直接内置 MCP。agent 先完成一部分工作，熟练用户在自己熟悉的工具里接着协作，不用把工作搬到新平台。

头条里的 Tim Simmons 就是这样用的：在 Claude Code 里通过 MCP 驱动 OpenArt 批量生成镜头，剪辑仍在 Premiere 里亲手做。他也提到，有些操作直接用平台更方便。

对做内容和做工具的人，判断标准可以是：哪些步骤能用一句话交代清楚、需要重复很多次，这些交给 agent；需要审美判断的部分留在人手里。做 SaaS 的人也可以想一想，自己的产品要不要开放 MCP 接口，好让用户的 agent 直接调用。
