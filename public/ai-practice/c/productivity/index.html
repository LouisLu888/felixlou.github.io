代码变更涨了 12 倍，Anthropic 七个人换掉了 Git

Anthropic 称，每天合并的代码变更从 5 月的约 2,500 次增加到 9 月的 30,000 多次。一个 7 人团队自建了版本控制系统，用五个月完成了从 Git 的迁移。

004 · 2026-10-13·本周动态

让 agent 守规矩，与其改说明文档，不如让提交直接失败

Geoffrey Huntley 用一个 pre-commit hook 拦下绕过诊断库的代码，并把纠正提示注入给 agent，自述遵守率变成「十次十中」；Simon Willison 则让 Codex 做了个小工具，好让密钥文件不经过模型。

003 · 2026-10-12·本周演示

不放心让 agent 上线代码，就让它先交「证据」再人工验收

教过 10 万多人用 AI 开发的 Micky 说，他还不信任 agent 处理用户在用的东西，所以让 agent 先提交改动前后的测试证据，人工审查只放在最后一步。

003 · 2026-10-12·本周动态

给 agent 一份旧插件当样板，让它读完新文档就写出新插件

Simon Willison 让 GPT-6 Astra 读 OpenAI 新发布的 Decisions API 文档，参照他已有的 llm-typesafe 插件，写出了 llm-openai-decisions 插件（0.1a0 预览版）。
