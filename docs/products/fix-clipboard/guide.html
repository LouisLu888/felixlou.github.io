1. 下载并放进应用程序

  1. 下载官方 GitHub Release 的 DMG。同一个包适用于 Apple Silicon 和 Intel。
  2. 双击 DMG，把 Fix Clipboard.app 拖到旁边的 Applications（应用程序）。
  3. 在 Finder 的「应用程序」里双击 Fix Clipboard。如果系统拦截，继续下面的首次打开步骤。
  4. 安装完成后，推出 Finder 中的安装磁盘。不要一直从 DMG、下载目录或 ZIP 中运行。

也可从版本页面下载 ZIP，解压后把 App 放到应用程序。页面同时提供 SHA-256 校验文件。

2. macOS 阻止打开时，这样处理

我暂时没有加入付费 Apple Developer Program。当前 App 使用本地 ad-hoc 签名，没有 Apple 认可的 Developer ID 签名，也没有经过 Apple 公证，因此 macOS 可能显示“无法验证开发者”或“Apple 无法检查 App 是否包含恶意软件”。

这类身份或公证提示，并不等于系统检测到了恶意软件。它表示 macOS 无法通过该验证流程确认此 App。只在确认下载来自本项目且文件未遭篡改后，才继续为这个 App 放行。

  1. 先尝试打开一次。从应用程序双击 Fix Clipboard。看到无法验证开发者／无法检查 App 的提示后，点击「完成」或关闭提示，保留 App。
  2. 打开苹果菜单  → 系统设置（System Settings）。
  3. 进入 隐私与安全性（Privacy & Security），向下滚动到安全性区域。

  5. 按系统提示使用 Touch ID 或 Mac 登录密码确认，再点击 打开（Open）。之后通常可以直接打开这个 App。

如果提示明确写着“将损坏你的电脑”“包含恶意软件”或“App 已损坏”，请停止安装，不要照着身份验证提示的教程继续放行。重新核对官方来源，必要时联系开发者。查看 Apple 官方说明。

整个过程只为你确认的这一个 App 添加例外，不需要关闭 Gatekeeper、SIP，也不需要粘贴任何终端命令。

3. 开始修复与检查

手动修复：先免费试一下

  1. 打开 Fix Clipboard 主面板，点击立即修复。
  2. 等待执行完成。它会启用 Mac 的剪贴板共享偏好，并重启当前用户的共享服务，接力可能短暂中断。
  3. 在手机上重新复制一小段文字，再到 Mac 粘贴。也试一下 Mac 复制、手机粘贴。执行完成仅表示命令完成，实际是否恢复以这一步为准。

诊断：看条件，不把绿勾当成功保证

  • Wi-Fi / Bluetooth / Handoff：展示本机开关或偏好状态，不能验证对方设备。蓝牙优先读取系统报告，只有读取失败时才提供额外授权检查。
  • VPN 绿色：未检测到已连接的系统 VPN。橙色表示检测到连接，请检查 VPN App 的 Local Network Sharing / Allow LAN；灰色表示状态未知。
  • 同时检查手机、iPad 上的 VPN。第三方代理可能漏检；工具不能解除 VPN 的局域网限制。Apple 官方通用剪贴板说明。

登录启动与后台运行

首次提示默认勾选登录启动，点击确认后才开启。它永久免费，可随时在主面板关闭。关闭窗口后 App 仍在菜单栏，点击笑脸剪贴板可以重新打开；菜单中的「退出」才会停止运行。

免费自动修复

在主面板手动开启「网络变化与 Mac 唤醒」。App 会在系统报告网络路径变化或实际睡眠唤醒后，等待网络可用、稳定 3 秒，并满足 10 秒冷却后自动尝试修复。合盖没有进入睡眠时，开盖不保证触发。它不是持续检测剪贴板内容，也不会每 4 小时定时重启。

还是不能粘贴？

确认两台设备登录同一 Apple 账户、打开 Wi-Fi / 蓝牙 / 接力并放在附近。重新复制后再试。持续失败时可按 Apple 的排查说明重启设备，或到 GitHub 反馈，附上 macOS 版本、App 版本和操作步骤，别发剪贴板内容或授权码。

4. 想继续看作者的分享？

打开 App 的「小红书 / 公众号」或网页的关注作者：小红书入口打开原帖，点击作者头像关注；公众号用微信扫码关注。这里分享实用技术、AI、产品和自动化方法。

关注完全自愿。不需要加私人微信、转账、入群、注册或发送任何激活码。工具不检查关注状态，关闭关注窗口即可继续使用全部功能。

5. 它会做什么，不会读取什么？

修复动作是启用本机剪贴板共享配置、重启当前用户的共享服务。免费自动修复把相同动作安排在网络变化或唤醒之后，工具不会为了判断故障而读取你的剪贴板。

  • 不读取、保存或上传剪贴板内容，不访问个人文件、照片或通讯录。
  • 诊断会读取必要的本机开关、偏好和进程状态。蓝牙系统报告可能包含设备信息；程序只提取开关结果，临时报告读取后删除，不展示或上传设备信息。
  • 没有使用行为追踪或遥测。免费版不调用支付或授权服务，也不生成安装标识或访问旧授权钥匙串。
  • 本机只保存功能设置和上次修复记录，不包含剪贴板内容。
  • 点击更新、帮助或官方文档会打开浏览器，对应网站按各自规则处理访问数据。微信与小红书关注由你主动操作，相关平台按各自规则处理。

你可以在 GitHub 查看源码，也可以阅读完整隐私说明。开源和上述功能范围有助于核查行为，但不能替代 Apple 公证或独立安全审计。

6. 更新、退出和卸载

更新：从菜单退出旧 App，下载新版本，替换 Applications 中的旧文件，再启动。设置保留；旧授权无需迁移。请看清版本号，避免把候选版替换成较旧稳定版。App 不会自动下载或安装更新。

卸载：先在 App 中关闭登录启动，再退出，将 App 移到废纸篓。免费版不需要激活。旧版遗留的授权钥匙串可自行通过“钥匙串访问”清理，服务名为 local.louis.fixclipboard.license；删除旧记录不影响免费版。
