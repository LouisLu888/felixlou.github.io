一次纽约行、一份报税，各开一个用完就归档的 AI 对话

投资人 Nikunj Kothari 用 Wabi 2.0 管家务：主 agent 看到航班信息就自动开一个旅行对话，行程结束后归档；孩子学校的事单开一个对话，和妻子共享。

谁·场景
风投合伙人、两个孩子的父亲 Nikunj Kothari。他用过 Wabi 1.0 但没坚持下来，这次试用 2.0 版。
怎么用
一个总调度 agent，按事务自动生成单一用途的对话：纽约出差、2025 年报税、孩子学校。单个对话可以分享给家人。
结果
他说纽约行程的对话是 agent 看到航班后自己建的，需要时提供帮助，回来后自动归档，报税也是这样。按他的说法，下载后马上就用上了。
你可以试
用你手上的个人助手，试着按事务分开对话（一次旅行、一次报税），事情办完就归档，家庭事务的对话和伴侣共享。
注意
要让它主动开对话，就得给它看行程等个人信息的权限。他的批评是它太主动，配套应用也还需要打磨。

Nikunj Kothari 在 X 上写了自己用 Wabi 2.0 的体验，并说明没收钱也没投资。他把个人 agent 分成两类：Muse 这种单线程助手，事情一多就混在一起；自己搭的多会话 agent 能共享上下文，但对话一直留着。

Wabi 的做法是一个总调度加按事务开的临时对话。他去纽约前，agent 根据看到的航班自动建了行程对话，回来后归档；2025 年报税也单开一个。孩子学校的对话分享给了妻子，两人看的是同一份上下文。

对普通家庭，可以借鉴的是组织方式：一件事一个对话，办完就收起，需要配合的那件事拉上伴侣。代价是要让 agent 主动建对话，就得开放航班、日程这类信息。他自己的批评是它太主动了。
