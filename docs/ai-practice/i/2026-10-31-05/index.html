同一个 Agent 任务，不用提示词缓存要贵 3.6 倍

Agent Arena 分析了 2.6 万个会话：前十名的 Agent 如果不用提示词缓存，一个任务的成本是用缓存时的 3.6 倍；Fable 5.1 的典型任务，用缓存 7.44 美元，不用 27 美元。

谁·场景
Latent Space 的 AINews 栏目汇总了本周和模型成本有关的几组数据，适合正在做 AI 产品、自己付模型账单的人。
怎么用
Agent Arena 统计了 2.6 万个 Agent 会话的成本。同期 Anthropic 调整了订阅档位：Max 5x 改名 Max，每月 100 美元；Max 20x 改名 Ultra，每月 200 美元。
结果
Agent Arena 称，缓存每失效一次，任务账单增加约 5%。Anthropic 宣布，通过验证的 Ultra 账户取消 5 小时会话限制，每周额度不变，新账户要等验证完成。
你可以试
把产品里 Agent 的调用日志按是否命中缓存拆开，算出每个任务的平均成本，再检查哪些步骤反复让缓存失效。
注意
3.6 倍是这批榜单 Agent 的统计结果，你的任务结构不同，节省比例也会不同。关于订阅补贴的估算来自第三方推算，未经核实。

Latent Space 本期汇总了几组成本数据。对做 Micro SaaS 的人最有用的是 Agent Arena 这组：用不用提示词缓存，同一个任务的成本差 3.6 倍；缓存只要失效一次，账单就多约 5%。做定价时，模型成本应该按实际缓存命中率算，不能直接拿 API 标价去乘。

订阅这边，Claude Ultra 取消了 5 小时限制，对重度个人开发者来说，用订阅干活的空间更大了。同一期还提到 SemiAnalysis 的一份推算：订阅只带来约 18% 的收入，却用掉了一半以上的算力。这个数字未经核实，不过它提醒了一个风险：今天便宜的订阅额度，不一定会一直这么便宜。

同期还有一条和流量有关的消息：Google 首席商务官 Philipp Schindler 说，AI Mode 的变现水平较低，影响了搜索收入。像头条那样靠 SEO 起家的生意，可以开始关注自己的搜索流量有没有变化。
