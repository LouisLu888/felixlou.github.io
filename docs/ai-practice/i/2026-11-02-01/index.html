Karpathy 周末两小时，用 HN 二十年评论重做 YouTube 推荐

Andrej Karpathy 让 Claude 把 Hacker News 二十年里的 4300 万条评论筛成 6,454 个反复被推荐的视频，做成网站并部署上线，他说一共用了约 2 小时。

谁·场景
Andrej Karpathy 不满意 YouTube 的推荐，周末给自己做了一个叫 HackerTube 的视频站。
怎么用
他用 Mac 上的 Claude Code 桌面版，默认 Opus 5.5、Medium effort，只和 Claude 对话，分析数据、写代码、部署都交给它；他自己只在浏览器里做了三件事。
结果
他说约 2 小时完成。网站不用登录，推荐状态存在本地浏览器里，评论分析数据打包成一个 zip 公开。
你可以试
挑一个你嫌推荐不准的信息源，找一份能下载的公开数据，让 AI 先做筛选和统计，再决定要不要做成页面。
注意
要申请 API key、开服务器、买域名，账号和付费这几步得本人去办；他是顶尖工程师，判断 AI 做得对不对的能力也是普通人比不上的。

Andrej Karpathy 在 X 上介绍了一个周末项目 HackerTube。他嫌 YouTube 推荐不好，就让 Claude 读完 Hacker News 二十年来的 4300 万条评论，挑出 6,454 个反复被人推荐的视频。他说用 Opus 5.5 花了大约 2 小时，观看体验好了很多。缩略图取的是视频中段的一帧，不用上传者反复测试过的点击图。底层的评论分析数据他打包成了一个 zip，建议别人「让你的 Claude 读它，做一个自己的版本」。

分工很清楚。他只和 Claude 对话，其余都交给 Claude，自己只在浏览器里做了三件事：在 Google Cloud 后台创建查询 YouTube 元数据的 API key，开一台 VPS，买域名。服务器开好后，他把 IP 给 Claude，让它更新、加固安全、部署并优化代码，这些都是 Claude 完成的。

可以借鉴的是这种拆法：需要账号、付钱、身份验证的事本人做，其余交给 AI。开工前先列出这几个人工节点，就知道卡点在哪。他说很多原本要几周甚至几个月的项目，现在几次尝试就能做出来。这句话放在一个数据公开、需求是他自己的周末项目上成立；涉及客户数据或线上业务的项目，安全加固和代码检查需要的时间会更多。
